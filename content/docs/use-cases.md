## How to read one

- **The prompt** What was typed into the client, with Copy to try it yourself.
- **The session** Each step of the agent: the tools it called with their arguments, what each tool answered and what the agent said. Go through it step by step or open all steps.
- **The outcome** The agent's answer with a chart and a table of the figures.

Secrets and private data are removed from every session before it is published. Long answers are shortened, no value is changed.
